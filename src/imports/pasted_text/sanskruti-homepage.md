# 1. VISUAL DIRECTION

Create an extremely premium visual identity.

Use a sophisticated editorial fashion aesthetic with:

* Warm ivory / cream background
* Deep charcoal or near-black typography
* Muted champagne / antique gold accents
* Subtle beige and earthy neutrals
* Large luxury fashion photography
* Generous whitespace
* Thin borders
* Elegant serif typography for headings
* Clean modern sans-serif typography for navigation and UI
* Minimal use of gold
* Soft shadows
* Large product imagery
* Editorial-style layouts
* Asymmetric image compositions where appropriate
* Large typography
* Refined micro-interactions

Avoid:

* Bright colors
* Excessive gradients
* Heavy shadows
* Cheap-looking gold effects
* Overcrowded layouts
* Too many decorative elements
* Generic Indian wedding templates
* Excessive traditional motifs
* Cluttered product cards

The overall aesthetic should feel like a **luxury fashion magazine combined with a premium e-commerce store**.

48–64px

H2:

12–14px

# 23. IMPORTANT DESIGN RULE

Do NOT make the website look like a cheap saree marketplace.

Avoid:

* Excessive red/maroon
* Heavy traditional borders
* Decorative mandala backgrounds
* Too many gold elements
* Crowded banners
* Flashy sale badges
* Excessive text
* Cheap gradients
* Generic e-commerce layouts

Instead, make Sanskruti feel like an **aspirational luxury fashion brand**.

Think:

**Minimal. Editorial. Elegant. Indian. Contemporary. Premium. Timeless.**

Create the complete responsive Figma design system, desktop screens, tablet screens and mobile screens with reusable components, auto-layout, proper spacing, typography styles, buttons, cards, navigation, product components, modals and interaction states.
